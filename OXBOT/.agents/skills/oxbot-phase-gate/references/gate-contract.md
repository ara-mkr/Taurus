# Baseline phase contract

Initial active phase P0: planning. Current work envelope P0-P2: scope, UI design and simulated frontend after owner approval. P3 desktop, P4 backend/read-only sources, P5 real actions/memory, P6 proactivity/phone, P7 wearable, P8 native voice/alarms/calls, P9 errands/finance/expansion, P10 listening, P11 release track require explicit advancement.

The owner can revise the roadmap; the agent cannot. A later release may occur for a narrow core without every advanced feature. A minimal privacy/support page may be needed for OAuth verification, but does not justify a full marketing build during UI work.

Gate evidence includes actual results, not a model's assurance. Product concept, prototype, simulation and production support must be labeled distinctly.
