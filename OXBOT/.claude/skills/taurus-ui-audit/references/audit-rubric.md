# Audit rubric

Hierarchy/readability 20; task/action clarity 20; layout/consistency 15; accessibility 15; complete and truthful states 15; original identity/restraint 10; performance/motion 5. Proposed passing threshold: 85 plus human approval and zero critical failures.

Critical failures: essential controls inaccessible; demo claims real sends/alarms; real personal data in fixtures; approval payload concealed; unknown outcome shown as success; obstructive overflow; locked-phase implementation. Evidence should include viewport/theme/scenario, screenshot or reproduction steps and actual test output.

Automated accessibility and screenshot tests are partial checks. Manual keyboard and visual review remain necessary. Distinguish not tested from passed. The auditor is not authorized to change phase state.
